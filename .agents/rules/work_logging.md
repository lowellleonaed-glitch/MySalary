# Work Logging Guideline (WORK_LOG.md)

ในการทำงานทุกครั้งที่ได้รับคำสั่งจากผู้ใช้:
1. บันทึกประวัติการทำงานลงในไฟล์ `WORK_LOG.md` ที่ root ของโปรเจกต์เสมอ
2. รูปแบบการบันทึกใน `WORK_LOG.md`:
   - **กระชับ เข้าใจง่าย ตรงประเด็น**
   - **ระบุเฉพาะชื่อไฟล์ที่แก้ไขสั้นๆ** (เช่น `index.html`, `app.js`, `style.css`, `sw.js`) โดยไม่ต้องใส่เส้นทาง path ยาวๆ
   - โครงสร้าง: วันที่/เวลา, คำสั่งที่ได้รับ, สิ่งที่ทำ, ไฟล์ที่แก้ไข, สถานะ
3. การตอบกลับใน Chat ให้ตอบสั้นๆ กระชับ และตรงประเด็น
