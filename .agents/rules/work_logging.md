# Work Logging Guideline (WORK_LOG.md)

ในการทำงานทุกครั้งที่ได้รับคำสั่งจากผู้ใช้:
1. ให้บันทึกประวัติการทำงานลงในไฟล์ `WORK_LOG.md` ที่ root ของโปรเจกต์เสมอ
2. รูปแบบการบันทึกใน `WORK_LOG.md`:
   - วันที่และเวลา (Timestamp)
   - คำสั่งที่ได้รับ (User Request / Task)
   - รายละเอียดสิ่งที่กำลังจะทำ / วางแผนทำ (Planned Action)
   - รายละเอียดสิ่งที่ทำเสร็จแล้วและไฟล์ที่แก้ไข (Completed Action & Modified Files)
   - ผลการทดสอบ (Verification Status)
3. การตอบกลับใน Chat ให้ตอบอย่างกระชับ สรุปสั้นๆ และแจ้งการบันทึกลง `WORK_LOG.md`
