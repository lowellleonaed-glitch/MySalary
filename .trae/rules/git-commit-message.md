- Keep commit messages short, concise, and direct (single line, max 15-30 characters).
- Use Conventional Commits format: `<type>: <summary>` (e.g., `feat:`, `fix:`, `refactor:`, `chore:`).
- State directly what changed without preamble or filler words.
- Do not include body text or bullet points unless strictly necessary.
