# 💼 SalaryHub — ระบบบันทึกรายรับ-รายจ่ายเงินเดือน & PWA

> เว็บแอปพลิเคชันจัดการเงินเดือน บันทึกกะและโอทีรอบ 16-15 ติดตามรายจ่าย วางแผนเป้าหมายการเงิน และคำนวณภาษี ภ.ง.ด.91 แบบ Client-Side 100% พร้อมรองรับ PWA ออฟไลน์

---

## ✨ ไฮไลท์ฟีเจอร์เด่น (Key Features)

- 💰 **คำนวณเงินเดือนแม่นยำ:** คำนวณฐานเงินเดือน, ค่าจ้างรายวัน, ค่ากะดึก, ค่าล่วงเวลา (OT 1.5x), ค่าอาหารเช้า, ค่าเดินทาง, เบี้ยขยัน, ค่าเป้าหมาย และค่าอาหารโอที
- 🌓 **รองรับการลาครึ่งวัน (Half-Day Leave):** หักค่าจ้างฐาน 50% แต่ยังได้รับเบี้ยเลี้ยงเดินทางและอาหารเช้าครบถ้วนตามระเบียบ
- 📅 **ปฏิทินบันทึกกะ/OT รอบตัดวิก 16-15 (Pay Period Auto-Sync):** คำนวณรอบวิกอัตโนมัติตามวันที่จริง พร้อมปุ่มบันทึกและซิงก์เข้าสูตรคำนวณทันที
- 🛡️ **คำนวณประกันสังคม & ภาษี ภ.ง.ด.91:** ตัดประกันสังคมตามเพดาน และประมาณการภาษีเงินได้บุคคลธรรมดาแบบขั้นบันได (Progressive Tax)
- 📊 **บันทึกรายจ่าย & เป้าหมายการออม (Savings Tracker):** แยกหมวดหมู่ค่าใช้จ่าย กราฟแสดงสัดส่วนรายรับ-รายจ่าย และคำนวณเวลาถึงเป้าหมายเงินออม
- 📱 **PWA & Offline Ready:** ติดตั้งลงบนมือถือแบบ App ได้ และใช้งานได้โดยไม่ต้องต่อเน็ต
- 🔒 **PIN Lock Screen:** ล็อกหน้าจอด้วยรหัส PIN (SHA-256) และระบบ Auto-Lock ป้องกันผู้อื่นแอบดูข้อมูลเงินเดือน
- 💾 **Privacy-First:** ข้อมูลทั้งหมดเก็บใน `localStorage` ของเครื่องผู้ใช้ ไม่มีการส่งข้อมูลขึ้น Cloud ภายนอก พร้อมระบบ Export/Import ข้อมูลสำรอง (JSON)

## 🚀 เริ่มต้นใช้งานในเครื่อง (Quick Start)

### ความต้องการของระบบ:
- [Node.js](https://nodejs.org/) (เวอร์ชัน 16 ขึ้นไป)

### คำสั่งสำหรับรันโปรเจกต์:
```bash
# รัน Local Development Server
npm run dev
# หรือ
npm start
```
เปิดใช้งานผ่านบราวเซอร์ที่: **http://localhost:3000**

### คำสั่งสำหรับรันการทดสอบ (Automated Tests):
```bash
npm test
```

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```
.
├── index.html                   # โครงสร้างหน้าเว็บหลัก (Tabs, Modals, PIN Overlay)
├── app.js                       # Logic หลักของระบบ (State, Payroll, Calendar, Storage)
├── style.css                    # สไตล์ดีไซน์ (Glassmorphism, Dark/Light Mode, Mobile Responsive)
├── sw.js                        # Service Worker รองรับ Offline PWA
├── manifest.json                # PWA App Configuration
├── package.json                 # คำสั่ง scripts สำหรับ dev & test
├── icons/                       # ไอคอนและ Launch screens
├── scripts/                     # สคริปต์เสริมสำหรับเจนเนอเรตไอคอน
├── tests/                       # ชุดทดสอบ Regression & Unit tests ทั้งหมด
├── data/                        # ข้อมูลและไฟล์ Excel สำหรับอ้างอิง
└── docs/                        # เอกสาร Design Specs, Plans และ HANDOVER.md
```
